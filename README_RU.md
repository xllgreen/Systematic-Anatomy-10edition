## О проекте

Данный проект систематически объединяет основные области анатомии человека, нейроанатомии, клинической прикладной анатомии и интегрированного китайско-западного анатомического анализа, охватывая **112 ключевых анатомических навыков**, разделённых на 8 основных категорий.

**Целевая аудитория** : Студенты-медики, клинические врачи, исследователи в области анатомии, ординаторы-хирурги

**Учебное пособие** : «Систематическая анатомия» (10-е издание) — People's Medical Publishing House (Главный рецензент: Дин Вэньлун; Главные редакторы: Цуй Хуэйсянь, Лю Сюэчжэн)

**⚠️ Предупреждение ⚠️** : Данный сборник навыков включает описания строения человеческого тела, анализ анатомических вариаций, оценку хирургических доступов и клиническую топическую диагностику. Он не заменяет профессиональное обучение анатомии или клиническую практику.

### Примеры запросов

#### 1. Запрос концепции
```bash
Расположение и отделы внутренней капсулы
```
```bash
## Внутренняя капсула (Internal Capsule)
Внутренняя капсула — это пластинка белого вещества, расположенная между хвостатым ядром, чечевицеобразным ядром и дорсальным таламусом. На горизонтальном срезе она имеет форму **« >< »**.

### Отделы
| Отдел | Расположение | Проходящие пучки волокон |
|-------|-------------|-------------------------|
| **Передняя ножка** | Между головкой хвостатого ядра и чечевицеобразным ядром | Лобно-мостовой путь, передняя таламическая лучистость |
| **Колено** | Место изгиба между передней и задней ножками | Корково-ядерный путь |
| **Задняя ножка** | Между чечевицеобразным ядром и дорсальным таламусом | Корково-спинномозговой путь, центральная таламическая лучистость, слуховая лучистость, зрительная лучистость |
...

### Клиническое значение
- **Повреждение колена внутренней капсулы** → Контралатеральный паралич мышц языка и нижней части лица (надъядерный паралич)
- **Повреждение задней ножки** → Контралатеральная гемиплегия (корково-спинномозговой путь) + контралатеральная гемианестезия (центральная таламическая лучистость)
```

#### 2. Анализ клинического случая
```bash
Пациент 65 лет, внезапная слабость правых конечностей и нарушение речи в течение 3 часов. Осмотр: мышечная сила правых верхней и нижней конечностей 0 баллов, центральный паралич лицевого нерва справа, снижение болевой и температурной чувствительности справа, отведение взора влево. Проанализируйте возможную локализацию поражения.
```
```bash
## Анализ случая

| Параметр | Проявление |
|----------|-----------|
| Возраст | 65 лет → группа высокого риска инсульта |
| Начало | Внезапное (острое) → сосудистая этиология |
| Двигательные нарушения | Правосторонняя гемиплегия (0) + центральный паралич лица → левый корково-спинномозговой и корково-ядерный пути |
| Чувствительные нарушения | Снижение болевой и температурной чувствительности справа → левая центральная таламическая лучистость |
| Взор | Отведение влево → левый лобный центр взора (лобное глазодвигательное поле) или деструктивное поражение |

### Топический диагноз
**Поражение задней ножки левой внутренней капсулы** (наиболее вероятно)
- Одновременное вовлечение корково-спинномозгового пути и центральной таламической лучистости
- Неполная форма классического **синдрома «трёх геми»** (гемиплегия + гемианестезия)
- Поражения внутренней капсулы могут сдавливать или затрагивать несколько пучков волокон в задней ножке

### Дифференциальный диагноз — Корковое поражение vs Поражение внутренней капсулы
| Признак | Поражение внутренней капсулы | Поражение коры головного мозга |
|---------|-----------------------------|-------------------------------|
| Распределение гемиплегии | Равномерное в верхних и нижних конечностях | Может преобладать в верхней конечности (или наоборот) |
| Потеря чувствительности | Равномерная на всей половине тела | Может быть более выраженной в одной области |
| Отведение взора | Может появляться или отсутствовать | Поражение лобного центра взора → отведение в сторону поражения |
| Афазия | Отсутствует | Возможна при поражении доминантного полушария |

### Неотложная помощь
1. Немедленная КТ головы для исключения кровоизлияния
2. Оценка показаний к тромболизису rt-PA (в течение 3 часов от начала)
3. Поддержание проходимости дыхательных путей, мониторинг АД и уровня глюкозы
4. Антиагрегантная терапия, статины
```

#### 3. Экзаменационные вопросы
```bash
Какое из следующих утверждений о внутренней капсуле является НЕВЕРНЫМ?
A. Расположена между хвостатым ядром, чечевицеобразным ядром и дорсальным таламусом
B. Колено содержит корково-ядерный путь
C. Задняя ножка содержит корково-спинномозговой путь
D. Повреждение внутренней капсулы не вызывает чувствительных нарушений
```
```bash
**Ответ: D. Повреждение внутренней капсулы не вызывает чувствительных нарушений**

**Объяснение:**
- A ✅ Верно. Внутренняя капсула — это пластинка белого вещества между хвостатым ядром, чечевицеобразным ядром и дорсальным таламусом
- B ✅ Верно. Колено внутренней капсулы содержит корково-ядерный путь, иннервирующий двигательные ядра черепных нервов
- C ✅ Верно. Задняя ножка содержит корково-спинномозговой путь, контролирующий произвольные движения туловища и конечностей
- D ❌ Неверно. Задняя ножка также содержит **центральную таламическую лучистость**, которая передаёт поверхностную и глубокую чувствительность от всего тела. Следовательно, повреждение внутренней капсулы может вызвать контралатеральную гемианестезию

**Дополнительно:** Полное повреждение внутренней капсулы → классический **синдром «трёх геми»**:
1. Контралатеральная гемиплегия (корково-спинномозговой путь)
2. Контралатеральная гемианестезия (центральная таламическая лучистость)
3. Контралатеральная гомонимная гемианопсия (зрительная лучистость)
```
